# WorkScout 1.0.0

První základní vydání desktopové aplikace WorkScout pro Windows. Verze představuje
technický a uživatelský základ pro budoucí vyhledávání pracovních nabídek a
správu celého životního cyklu žádostí.

## Hlavní funkce

- Úvodní nastavení samostatného Gmail účtu a hlavního e-mailu uživatele.
- Ověření Gmail připojení přes IMAP a SMTP.
- Bezpečné lokální uložení app passwordu pomocí Windows DPAPI.
- Ukázkový režim bez nutnosti připojit e-mail.
- Lokální SQLite databáze spravovaná pomocí EF Core migrací.
- Výběr pracovních portálů a filtrování demonstračních nabídek podle profese.
- Připravené rozhraní `IJobSource` pro budoucí API a scraper adaptéry.
- Databázový základ pro žádosti, jejich stavy a příchozí komunikaci.
- Unit a integrační testy spouštěné automaticky v pull requestech.

## Omezení první verze

Pracovní nabídky jsou pouze demonstrační. Verze zatím neobsahuje skutečný scraper,
automatické odesílání CV, pravidelné čtení e-mailů ani automatické odpovědi.

Release je framework-dependent a vyžaduje .NET 10 Desktop Runtime pro Windows x64.
